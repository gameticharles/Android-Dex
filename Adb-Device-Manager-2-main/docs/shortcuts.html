Keyboard Shortcuts

All global hotkeys for ADB Device Manager in one place. Shortcuts are organised by category for quick reference. All hotkeys are global — they work even when the app window is minimised.

All shortcuts listed below are global hotkeys and work even when ADB Device Manager is minimised or running in the background.

Mirroring & Audio

FeatureShortcutDescription
Screen Mirroring
Alt+S
 Start or stop screen mirroring.
Audio Streaming
Alt+A
 Stream device audio output to the PC.
Input Control
Alt+I
 Enable mouse & keyboard control of the device.

Android DeX & Desktop Mode

FeatureShortcutDescription
Android DeX
Alt+Shift+D
 Launch the Android DeX multi-window desktop.
Desktop Mode
Alt+D
 Launch Android in desktop-style multi-app mode.
File Transfer
Alt+F
 Open the File Transfer panel.

Media & Volume

FeatureShortcutDescription
Play / Pause
Alt+Space
 Play or pause the current media.
Previous Track
Alt+←
 Skip to the previous track.
Next Track
Alt+→
 Skip to the next track.
Increase Volume
Alt+↑
 Raise the device volume.
Decrease Volume
Alt+↓
 Lower the device volume.

System Controls

FeatureShortcutDescription
Power Toggle
Alt+P
 Turn the device screen on or off.
Bluetooth Toggle
Alt+B
 Toggle Bluetooth on the device.
Voice Assistant
Alt+V
 Open the device voice assistant.
Take Screenshot
Alt+Shift+S
 Capture a screenshot of the device screen.

Navigation & Window

FeatureShortcutDescription
Toggle App Window
Alt+O
 Show or hide the ADB Device Manager window.
Home Button
Alt+Home
 Send the Android Home action.
Back Button
Alt+Backspace
 Send the Android Back action.
